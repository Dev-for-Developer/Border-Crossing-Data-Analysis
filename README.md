This project focuses on an in-depth analysis of U.S. border traffic data using Python, with the goal of uncovering trends, patterns, and insights across multiple dimensions such as time, location, and mode of transport. The dataset includes historical records of border crossings, which are analyzed and visualized to support data-driven decision-making and policy evaluation.

1.	Monthly and Seasonal Trends – Identifying peak traffic periods and seasonal variations.

2.	Border and State-Wise Comparison – Comparing traffic across U.S.-Canada, U.S.-Mexico borders, and individual states.

3.	Top 5 Busiest/Least Busy Ports – Highlighting high and low traffic ports.

4.	Mode of Transport Analysis – Examining traffic by vehicles, trucks, trains, and pedestrians.

5.	Geospatial Visualization – Mapping traffic data using Geo Pandas, resolving common CRS and plotting issues.

This end-to-end data analysis project not only strengthens technical skills in data manipulation, visualization, and geospatial analysis but also provides real-world insights into cross-border movement patterns that can be valuable for planners, policymakers, and researcher
